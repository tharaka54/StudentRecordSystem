# Report visual assets

The three report diagrams are supplied as editable `.drawio` XML sources, matching SVGs and high-resolution PNGs. Open a `.drawio` file with diagrams.net using File > Open From > Device. The shapes, text and connector waypoints are editable. Their plain UML-style presentation is inspired by the supplied student samples; their content describes Tharaka's own application. The exports were generated programmatically, not captured from the draw.io application.

`code_screenshots/listing-01.png` through `listing-12.png` are browser screenshots of a syntax-highlighted code viewer. The viewer shows report excerpts with line numbers local to each excerpt, not original file line numbers. Captions identify source files, omissions and illustrative examples. Listing 10 is an author-created Go/Java comparison; other listings illustrate the submitted Go implementation. These are code illustrations, not proof of execution. Runtime evidence remains in `verification` and the five application screenshots.

The report retains selectable application code in Appendix A as requested by the assignment brief. The complete source is included in the application folder.
